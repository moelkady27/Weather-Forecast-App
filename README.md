# 🌦️ Weather Forecast App

A simple Android weather forecast app built using **Kotlin** and the **Android SDK**, without any third-party libraries. It displays current and future weather information in a clean and user-friendly UI.

## 🚀 Features

- 🔍 Search by fixed location (customizable)
- 🌤 View 5-day weather forecast
- 🕐 Hour-by-hour weather data for the current day
- 💾 Local caching using `SharedPreferences`
- 🔄 Swipe-to-refresh functionality
- ⚡ Network error handling
- ✅ No third-party libraries (e.g., Retrofit, Coroutines, Room, etc.)

## 🛠️ Technologies Used

- Kotlin
- Android SDK
- SharedPreferences (for caching)
- HttpURLConnection (for API calls)
- Geocoder (for reverse geocoding)
- ViewBinding

## 📌 Requirements
- Android Studio Giraffe or later
- Android SDK 26+
- No external dependencies (no Retrofit, no Coroutines, etc.)
